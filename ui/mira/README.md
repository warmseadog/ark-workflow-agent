# mira UI — 2026-09-30

最新独立 UI 预览源码：白色主界面、脏紫渐变、统一字体层级与间距、Lucide 线性图标及圆润浮层。

## 运行

在仓库根目录运行：

```sh
python -m http.server 4173 --directory ui/mira
```

访问 http://127.0.0.1:4173/mira-cover.html 。无需构建和外部 CDN。

## 页面与代码

- `mira-cover.html`：全屏 MV、轮播、播放控制、本地素材选择。Log in 在当前页打开居中登录框，背景整体压暗，关闭/遮罩/Esc 返回，不跳转独立登录页。
- `mira-workspace.html`：保留原工作台布局的统一视觉预览。
- `mira-login.html`：保留的独立登录样式参考，首页不跳转到它。
- `assets/mira-system.css`：跨页面共享视觉变量与组件规则。
- `assets/mira-original-layout.css`：原工作台布局快照。
- `assets/mira-workspace-skin.css`：工作台品牌覆盖层。
- `assets/mira-icons.js`：Lucide 图标子集，许可证位于 assets/vendor/lucide-LICENSE。
- `assets/mira-workspace-preview.js`：仅预览事件处理，明确提示服务尚未接入。
- `assets/brand/`：mira 透明字标。
- `assets/cover/`：经用户明确授权公开的两条原始人物 MV 和相应定帧图。

## 视频说明

首页原视频通过 object-fit: cover 全屏裁切，不拉伸、不使用模糊填边。**这不是原生16:9重新生成的成片**；原生横屏生成尚未完成。静音循环播放，系统开启减少动态效果时不自动播放。素材为原始560×752，分别约5秒、4秒。

未纳入被否决的模糊填边版、未确认的AI重绘海报、旧品牌实验稿和用户私有业务资料。

## 生产接入边界

本次只增加 ui/mira/，没有覆盖 app/templates、app/static、认证路由、模型接口或生产数据，不等同服务器上线。

1. 保留现有认证、CSRF、权限隔离、上传校验、任务队列和草稿恢复。将首页登录弹窗接到现有认证接口，不建立第二套账号体系。
2. 当前登录输入禁用，按钮明确为“查看工作台预览”；不会发送凭据，不冒充真实登录。
3. 将样式和图标适配到真实模板、保留生产业务脚本并完成回归后再发布，不能直接用静态预览替换后端模板。
4. **不要在生产页面加载 mira-workspace-preview.js**：它有意拦截提交/上传，展示未接入提示。
5. 模型、清晰度和时长选项必须来自真实后端；此包不生成、不上传、不保存任务，不调用外部付费接口。
6. 生产媒体可改为经授权的对象存储/CDN；修改首页 curated 清单即可。
