## 运行

在仓库根目录运行：

```sh
python -m http.server 4173 --directory ui/mira
```

访问 `http://127.0.0.1:4173/mira-cover.html` 默认播放朱红篇；直接查看第五条窗景篇：`mira-cover.html?film=windowlight`。无需构建或外部 CDN。

## 素材与播放

素材由用户提供；用户已要求同步至此公开仓库。首页采用 `object-fit: cover`，不拉伸、不加模糊填边。街头、暮色原片为竖屏素材，通过裁切填满视口，并非重新生成横屏；日光、朱红、窗景原片本身为 16:9。手机仍按视口裁切。

静音循环播放；减少动态效果下默认暂停，仍可手动播放。浏览器自动播放或网页全屏限制不能由站点绕过。不包含被否决的海报、模糊填边版、私人业务资料或账号凭据。

## 接入边界

这是 `ui/mira/` 独立预览的同步，不覆盖已存在的 `app/templates`、`app/static`、后端逻辑或生产数据，不等同服务器部署。

登录框输入禁用，工作台明确为视觉预览，不会上传、生成或保存任务。接入生产时须保留原认证、CSRF、权限、上传校验、任务队列和草稿恢复；样式需适配真实模板并回归验证。

**不要在生产页面加载 `mira-workspace-preview.js`**，它会有意拦截提交。模型、画质、时长等必须来自真实后端能力。
