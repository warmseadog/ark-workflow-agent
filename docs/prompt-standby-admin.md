# 后台提示词机制与待用版本（2026-10-07）

本次只增加后台说明和待用存档能力。未修改默认模板标识、默认正文、素材规则拼接、生成请求或任务调度，不包含启用版本的能力。

## 后台使用

管理员与超级管理员均可从 `/admin/settings#prompts` 进入：

1. **当前生效机制**：读取数据库中实际保存的默认模板，显示默认名称、正文、规则版本、草稿与任务的生效范围，以及素材联动示例。不会用源码默认正文覆盖数据库内容。示例使用人物、衣服、独立围巾和独立手饰，不触发模型调用，也不是实际任务的完整最终请求。
2. **保存待用版本**：选择来源共享模板、填写名称、编辑候选正文、添加备注后保存。继承来源规则版本，保存为新记录；不进入制作页模板列表，不改变默认选择。
3. **待用版本记录**：显示最近 100 条，展开查看候选正文、备注、来源正文快照及保存时的素材规则示例。更早记录仍在数据库中，本期没有分页入口。记录不可覆盖；后续调整可复制正文另存。
4. **直接编辑共享模板**：保留原有入口，默认折叠并标示生效范围。直接保存默认模板仍会影响之后新建的草稿。需要暂存时，应使用待用入口。

围巾与手饰既可能出现在保存正文中，也仍受现有素材联动逻辑约束；本次只展示这一事实，不添加或移除相关规则。线上之前恢复的旧正文在本次更新中应保持原样。

## 存储与隔离

- 新模块：`app/prompt_standby.py`，新接口：`GET/POST /api/admin/prompt-standby`。
- 独立存储：全局配置存储根目录下 `private/prompt-standby.db`，首次保存时创建；纳入常规数据备份时需包含该文件。
- 每条记录保留候选名称、正文、备注、时间、来源模板标识与名称、来源正文快照、规则版本、规则源码摘要及当时的示例文本。
- 规则摘要与示例用于核对，不能恢复或执行历史规则代码。本期不能通过后台修改规则代码或切换全局默认版本。
- 现有 `local-preferences.db` 的模板表不写入待用记录；生产草稿、模板列表与工作进程不读取新数据库。
- 权限沿用共享模板：管理员和超级管理员共用记录；普通用户无法访问。写操作沿用现有同源及 CSRF 校验。拒绝额外的 `activate`、`is_default`、`rule_version` 等字段。
- 读取共享模板沿用原有数据库初始化流程，不增加任何迁移；已执行过的迁移不会因本功能重新执行。

## 回退

本改动作为独立提交保留。需整体撤回时，对本次功能提交执行 `git revert <本次功能提交>` 并按既有发布流程部署；不要回退之前独立执行的线上提示词正文恢复操作。

撤回代码后，`private/prompt-standby.db` 可以原样保留，旧版本不会读取它。无需恢复、删除或替换 `local-preferences.db`，避免覆盖用户之后的合法模板修改。待用记录不曾生效，因此撤回本功能不需要修改生产提示词。
