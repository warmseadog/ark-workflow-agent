# 人物视频预览与生成资格分离

问题：自有上传视频与已从真人库移除的文件内容相同，原来的文件、缩略图访问路径复用了生成素材授权检查，因此返回 404。用户的实际视频还采用 HEVC 编码，浏览器播放兼容性需要处理。

实现：

- 本账号存储中的自有上传文件可以预览，不以人物库移除状态阻止播放。跨账号素材仍无法通过 ID 读取；带共享来源标记的镜像保留原访问授权检查。
- 新增 `/api/production/assets/{id}/preview`，仅用于人物视频，首次点击时生成 H.264/AAC、yuv420p、faststart 预览并缓存，支持 Range 请求。保留原始文件与 SHA-256，生成仍使用原文件。转码限制并发、时长和执行时间。
- 新增 `/reference-status`，区分已保存待检查、已有检查通过记录、失败或移除阻断。页面读取该状态，显示具体原因；状态未确认或不可用时禁用生成按钮。提供重新检查状态和选择可用人物素材入口。
- 直接上传的已知真人文件需要从人物库选用，保留人物授权关联。预览不改变官方 `FaceMismatch`、删除标记或生成权限；生成流程仍有服务器端授权和官方校验。
- 未打开视频时只加载封面，关闭播放器释放视频资源。

验证：本地 32 项 API、浏览器和人物视频回归测试通过，覆盖桌面/手机、重新上传已移除内容、H.265 转 H.264、播放与关闭、缓存、Range、跨账号和撤销共享访问、状态提示和更换素材后的提交入口恢复。服务器 11 项测试通过。测试使用模拟官方请求，没有付费生成。

使用生产数据库副本及用户 `yoyo人脸视频1.mp4` 的副本检查：缩略图 200，预览 200，Range 206，实际输出 H.264/yuv420p，原文件不变。该原素材当前仍标记为移除，官方此前 `FaceMismatch` 的结果没有被改写。
