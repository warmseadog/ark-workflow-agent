# 默认提示词与独立参考优先

新建任务默认选择「默认提示词」并使用管理员当前保存的正文。原「动作保留」改名为「默认提示词2」，保留正文及原版素材联动行为。

新版规则：

- 动作参考视频只决定动作、运镜、构图和节奏。
- 未启用独立发型时，头发以主人物参考图为准；人物视频模式则以人物参考视频为准。两者都不采用动作视频的发型。
- 启用独立发型、场景、包包、帽子、手表、鞋子、项链、眼镜或耳环后，该类别只采用对应参考，忽略其他素材的同类元素，不混合、继承或叠加旧元素。
- 场景未启用时保留原视频背景；仅启用场景文字时按文字替换；图片和文字同时存在时，文字只补充图片未指定的细节。
- 图片存在但关闭「本次使用」时，不生成该类别独立参考规则；不意味着禁止原有素材中出现该物品。

制作页上方编辑模板正文，下方「本次完整提示词」只读显示实际组合结果。参考素材、正文或模型变化后自动更新。预览失败会明确显示原因，并阻止新的生成提交；可点击「刷新提示词预览」重试。页面预览与模型提交共用后端组装函数，不额外调用识图或文字模型。

模板的 `rule_version` 和任务的 `prompt_template_id`、`prompt_rule_version` 会保存。另存新版模板保留新版规则；已有草稿、历史快照和复制任务保持其原版本，未携带版本的旧记录按 `legacy-v1` 处理。恢复旧稿不会自动改成新版，用户可主动点击新版模板。

迁移仅在共享模板库执行一次：增加新版、重命名原 `default-0`；不重建此前删除的其他内置模板，不覆盖用户正文。删除新版后不会重建，也不会暗中继续将其作为新任务默认正文。个人模板库不会得到额外系统模板副本。

数据库增加规则版本字段后，降级检查要求目标版本具备 `exclusive-prompts-v2` 能力，避免旧程序不识别新模板结构和任务规则。发布使用现有完整发布包、维护窗口和一致性快照流程，不覆盖任务数据库。

测试覆盖迁移与删除、权限、草稿复制与恢复、各类独立元素、人物图/视频模式、补充图编号、场景描述、三种供应商协议和视频编辑模式的预览一致性，以及桌面/移动浏览器的模板切换、乱序回复和失败阻止提交。没有执行付费生成；最终画面遵循程度仍取决于视频模型。
