# 使用帮助与站内反馈

工作台侧栏的「帮助与反馈」和登录页的「联系」均打开 `/help`。帮助说明可在登录前阅读；启用账号的部署须登录后才能提交反馈、查看自己的反馈和管理员回复。无法登录或需要账号时，通过账号发放管理员已有的联系渠道处理。

## 开始制作

1. 在「制作流程」选择动作参考视频、衣服参考图和人物素材。真人使用人物库中已授权的素材；只上传自己有权使用的内容。
2. 按需设置场景、发型、配饰、提示词、模型、画质、比例、时长及声音。选择素材前阅读入口旁的格式、大小和尺寸要求。
3. 等待素材保存后点击「生成视频」。任务使用提交时的素材快照，后续编辑不会改变已提交的任务。
4. 在「任务记录」查看进度、任务详情和错误原因。完成后可以播放、下载，作品也会进入视频库。关闭网页不会取消后台任务。

上传入口与帮助页从 `/api/support/config` 读取当前限制。模型允许的参考图总数、合计视频时长、画质等来自制作页的模型选项；素材能够入库，不代表每个模型都能使用。要求未读取时可到帮助页点击「重新读取要求」。

## 出错后的下一步

- 「排队中」只有在任务尚未开始、未提交给服务商时才能取消排队。
- 「提交结果待确认」时不要重复提交或重新生成。先联系管理员核对服务商的原任务记录。
- 出现「继续查询 / 下载」时，它查询原任务并获取结果，不重新创建视频生成任务。
- 人物素材显示「自动查询已停止」时，可在人物库点击「继续检查原记录」。素材明确被拒绝时按原因更换素材。
- 上传或草稿保存失败时保留页面，检查网络后重试保存。版本冲突可选择「保留当前修改」。
- 复制为草稿后生成、重新生成、无声重试都会创建新任务。操作前先确认原任务是否已经被服务商接收。

错误提示和失败任务详情提供可复制的「问题编号」。在提交待确认的任务行点击「联系管理员」，帮助页会预填任务名称、可用的问题编号，以及任务时间/编号上下文；无需粘贴完整服务日志。

## 用户反馈与管理员处理

用户在帮助页填写问题描述，点击「提交反馈」，随后在「我的反馈」查看处理状态与管理员回复。可以点击「刷新反馈」重新读取；无需反复提交同一问题。问题描述长度与待处理反馈上限以表单前显示的当前配置为准。请勿提交密码、API Key、认证二维码或敏感原始素材。

管理员从侧栏「反馈处理」进入 `/admin/support`，按待处理/已处理筛选反馈，核对任务和供应商记录后填写「管理员回复」，选择处理状态并保存。用户只能看到自己的记录与回复。反馈留在本站，由管理员在后台处理。

关闭账号认证的本机单用户模式允许本机反馈及处理，界面会显示本机模式提示；公网匿名访问不会因此获得提交权限。

## 费用确认

当前版本没有站内扣款功能，也没有配置线下收费标准。第三方模型、解析和存储服务的实际费用应以供应商规则和账单为准。生成入口、链接解析入口及帮助页显示费用说明；如有账号使用或线下收费安排，由账号发放管理员说明价格、收费时点和失败后的处理方式。继续查询原任务与新建生成任务应分别核对。

本地工作区的这些修改需经正常发布后才会在服务器生效。
