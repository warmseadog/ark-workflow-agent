# 视频模型配置

当前 `/`、`/v1`、`/studio` 均直接打开独立制作页面，使用 `production.html` 和独立页面资源，不挂载素材发现、成功案例或队列导航，也不请求发现与案例 API。原模块代码和数据保留供后续接入。

制作工作台右下角的“视频模型设置”集中管理服务预设、Base URL、API Key、模型 ID、时长、分辨率和帧率显示。主制作页面仅展示参考视频、衣服和人物三个输入入口，提示词与模板默认收起。

右下角并排放置“打码设置”和“视频模型设置”。“打码设置”包含“预览打码视频”按钮与播放器。仅选择参考视频即可预览，不需要先选图片。正常生成操作会自动准备打码视频；素材和参数未变化时复用已完成的打码任务，变更后重新处理。原先独立的“开始打码”和两个确认步骤已从页面移除。

预设只填入初始值，所有地址、端口和模型均可编辑：

| 预设 | Base URL | 默认模型 ID |
| --- | --- | --- |
| 火山方舟官方 | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seedance-2-0-260128` |
| toapis.cn | `https://toapis.cn/v1` | `seedance-2` |
| 自定义 | 用户填写 | 用户填写 |

选择自定义后可在“高级配置”选择对应接口格式。端口直接写在 Base URL 中。两个预设没有可自由设置的 fps 字段，因此界面显示“由模型决定”；自定义适配层可保存 fps。

配置保存在 `STORAGE_DIR/private/generation-settings.json`，由本地后端读取。此目录已被项目的 `storage/*` 忽略规则覆盖，不通过静态文件路由公开。Key 保存在本机配置文件中，未加密；不写入浏览器存储，不随 GET / PUT 配置响应回显。API 仅接受本机访问及同源写入。留空保留当前地址的 Key，切换地址或协议会清除旧 Key 的沿用，勾选“清除”可删除。

已接入三种接口格式：火山方舟、toapis.cn 和自定义适配层。点击生成后，后端使用提交时的已保存配置快照，自动打码并提交任务、轮询状态、下载结果。真实模式失败会显示原因，不会退回演示输出。所有人物图、衣服图都会传入：第一张人物为 @Image1，第一张衣服为 @Image2，随后是其余人物图和衣服图；预设模型合计最多 9 张。

“测试连接”位于保存按钮旁，使用当前填写但尚未保存的配置；空 Key 只在相同地址及协议时沿用已保存值，测试不保存、不上传素材、不创建视频任务。方舟读取视频任务列表，只验证接口与鉴权；ToAPIs 读取视频模型目录，额外确认模型 ID 可见。它们不保证模型已开通全部生成权限、余额充足或素材被接受。

### 方舟的公网视频地址

方舟官方生成接口要求参考视频为公网 URL 或素材 ID，不接受本地路径、127.0.0.1 地址或视频 Base64。使用方舟时，可在后台配置中启用 TOS 对象存储（详见 [后台配置说明](admin-settings.md)），或在高级配置的“工作台公网地址”填写已配置反向代理的工作台地址。以下令牌地址说明仅适用于工作台公网地址方式。该地址必须能从公网读取 `/api/reference-videos/` 路径。程序不会自动建立公网隧道或部署服务。每次提交仅为当前打码视频生成随机令牌地址，2 小时后过期；不公开原视频、Key 或任意文件。重启会使旧令牌失效。此字段缺失时在开始处理前给出明确提示。

ToAPIs 会把打码视频上传到同一配置服务商的 `/uploads/videos`，无需工作台公网地址。不会把方舟 Key 用于 ToAPIs；切换地址或接口格式后需填写对应 Key。

生成提交不自动重试，以免重复创建付费任务。提交成功立即记录服务商任务 ID；查询遇到短暂超时、429 或 5xx 最多重试 2 次。后续失败保留远端任务 ID，方便在服务商控制台核对。连接测试和生成错误不回显 Key。

已核对的接口资料（2026-09-23）：

- [火山方舟创建视频生成任务](https://docs.volcengine.com/docs/82379/1520757?lang=zh)
- [火山方舟官方 SDK](https://github.com/volcengine/volcengine-python-sdk/blob/master/volcenginesdkarkruntime/resources/content_generation/tasks.py)
- [ToAPIs Seedance 2 文档](https://docs.toapis.com/docs/cn/api-reference/videos/seedance-2/generation)
- [ToAPIs 参考视频上传](https://docs.toapis.com/docs/cn/api-reference/uploads/videos)

接口差异：方舟要求参考视频的公网 URL 或素材 ID，本地回环 URL 不可用；toapis 提供先上传视频再生成的独立流程。两个平台的请求体和轮询路径不同，不能只替换 Base URL。
