# 视频模型配置

当前 `/`、`/v1`、`/studio` 均直接打开独立制作页面，使用 `production.html` 和独立页面资源，不挂载素材发现、成功案例或队列导航，也不请求发现与案例 API。原模块代码和数据保留供后续接入。

制作工作台右下角的“生成设置”只提供模型下拉框、清晰度和本次视频时长。点击“应用到当前视频”后写入当前草稿，不修改全局配置；取消或关闭不会应用尚未确认的选择。刷新恢复已应用参数，任务提交时冻结其私有连接快照。

服务预设、Base URL、API Key、模型 ID、协议、帧率和默认参数统一位于 `/admin/settings#model`。这里同时提供模型目录：显示名称、排序、已验收状态和前台开放开关。沿用升级前当前配置的模型；新增模型需要先在服务商控制台完成当前账号的实际生成验收，再在后台确认并开放。连接测试本身不验证生成权限。

模型目录位于 `STORAGE_DIR/private/model-catalog.json`；验收记录绑定服务商、协议、地址和密钥的摘要，改换地址或密钥后失效。仅改变默认模型不会自动开放尚未验收的模型。模型启用后刷新制作页读取最新目录。已有草稿若使用已停用的模型，可恢复编辑，但不能新提交任务，需重新选择可用模型。已提交任务继续使用冻结快照。

`GET /api/production/model-options` 只返回用户所需能力和默认值，不返回服务地址、密钥或协议。草稿模型仅保存 `model`、`duration`、`resolution`；旧草稿中相同的连接字段可以迁移，不能借任务字段覆盖后台连接。后台 API 保持原有本机/同源访问保护；本次拆分没有增加多用户角色权限系统。

已内置官方 Seedance 2.5、2.0、2.0 Fast、2.0 Mini 的能力；toapis/custom 继续沿用各自协议。

| 模型 | 清晰度 | 参考图总数 | 参考视频总时长 | 当前制作方式 |
| --- | --- | --- | --- | --- |
| 2.5 | 480p / 720p / 1080p | 30 | 30 秒 | 视频编辑，跟随原视频时长与比例 |
| 2.0 | 480p / 720p / 1080p / 4K | 9 | 15 秒 | 参考生成，输出 4–15 秒 |
| 2.0 Fast / Mini | 480p / 720p | 9 | 15 秒 | 参考生成，输出 4–15 秒 |

2.5 模型 ID：`doubao-seedance-2-5-260628`。当前产品统一按“编辑 @Video1”提交，`duration=-1`、`ratio=adaptive`，不开放与编辑时长冲突的任意输出时长；保留 MP4 下载路径。人物视频素材入库允许 2–30 秒，生成时按所选模型检查与动作视频的合计时长。单段视频 50 MB、参考图片总共 45 MB 等现有保守大小限制继续保留。

2.5 的本地请求构造与校验已适配，实际生成权限仍以账号验收为准。新模型不会因接入代码而标记为已验收。

右下角并排放置“打码设置”和“生成设置”。“打码设置”包含“预览打码视频”按钮与播放器。仅选择参考视频即可预览，不需要先选图片。正常生成操作会自动准备打码视频；素材和参数未变化时复用已完成的打码任务，变更后重新处理。

后台预设只填入初始值，所有地址、端口和模型均可编辑：

| 预设 | Base URL | 默认模型 ID |
| --- | --- | --- |
| 火山方舟官方 | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seedance-2-0-260128` |
| toapis.cn | `https://toapis.cn/v1` | `seedance-2` |
| 自定义 | 用户填写 | 用户填写 |

选择自定义后可在“高级配置”选择对应接口格式。端口直接写在 Base URL 中。两个预设没有可自由设置的 fps 字段，因此界面显示“由模型决定”；自定义适配层可保存 fps。

配置保存在 `STORAGE_DIR/private/generation-settings.json`，由本地后端读取。此目录已被项目的 `storage/*` 忽略规则覆盖，不通过静态文件路由公开。Key 保存在本机配置文件中，未加密；不写入浏览器存储，不随 GET / PUT 配置响应回显。API 仅接受本机访问及同源写入。留空保留当前地址的 Key，切换地址或协议会清除旧 Key 的沿用，勾选“清除”可删除。

已接入三种接口格式：火山方舟、toapis.cn 和自定义适配层。点击生成后，后端使用提交时的已保存配置快照，自动打码并提交任务、轮询状态、下载结果。真实模式失败会显示原因，不会退回演示输出。所有人物图、衣服图都会传入：第一张人物为 @Image1，第一张衣服为 @Image2，随后是其余人物图和衣服图；数量限制随所选模型变化。

“测试连接”位于保存按钮旁，使用当前填写但尚未保存的配置；空 Key 只在相同地址及协议时沿用已保存值，测试不保存、不上传素材、不创建视频任务。方舟读取视频任务列表，只验证接口与鉴权；ToAPIs 读取视频模型目录，额外确认模型 ID 可见。它们不保证模型已开通全部生成权限、余额充足或素材被接受。

### 方舟的公网视频地址

方舟官方生成接口要求参考视频为公网 URL 或素材 ID，不接受本地路径、127.0.0.1 地址或视频 Base64。使用方舟时，可在后台配置中启用 TOS 对象存储（详见 [后台配置说明](admin-settings.md)），或在高级配置的“工作台公网地址”填写已配置反向代理的工作台地址。以下令牌地址说明仅适用于工作台公网地址方式。该地址必须能从公网读取 `/api/reference-videos/` 路径。程序不会自动建立公网隧道或部署服务。每次提交仅为当前打码视频生成随机令牌地址，2 小时后过期；不公开原视频、Key 或任意文件。重启会使旧令牌失效。此字段缺失时在开始处理前给出明确提示。

ToAPIs 会把打码视频上传到同一配置服务商的 `/uploads/videos`，无需工作台公网地址。不会把方舟 Key 用于 ToAPIs；切换地址或接口格式后需填写对应 Key。

生成提交不自动重试，以免重复创建付费任务。提交成功立即记录服务商任务 ID；查询遇到短暂超时、429 或 5xx 最多重试 2 次。后续失败保留远端任务 ID，方便在服务商控制台核对。连接测试和生成错误不回显 Key。
