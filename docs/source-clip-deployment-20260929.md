# 视频片段时长与清空参考图发布

## 行为

- Seedance 2.5 编辑流程支持“跟随完整视频”和“指定片段时长”。后者接受 4–30 整数秒，起点可调整，范围不能超出原片。
- 片段参数作为独立 source_clip 草稿/任务字段持久化。旧草稿默认完整视频，模型调用继续采用编辑任务要求的 duration=-1。
- 提供原片片段预览；打码预览和正式生成都先截取同一片段，缓存键包含片段参数。保留原视频与音轨，重编码截取失败不复用半成品。
- 人物视频的时长合计校验使用动作片段的时长。切换至非编辑模型恢复原有生成秒数设置。
- “清空参考图”位于主页面参考图计数旁，清空所有图片类别、关闭可选图片项、刷新状态并自动保存。保留视频、提示词正文、素材库和历史任务，不调用素材删除接口。

## 验证

- 完整线上基线隔离测试：74 passed，1 skipped（Windows 无符号链接权限的既有测试）。覆盖真实 FFmpeg 截取帧与音轨、边界校验、草稿持久化、缓存隔离、任务与预览。
- 本地工作区相关测试：35 passed。补齐本地缺失的 5 个既有线上依赖，不额外覆盖服务器依赖文件。
- 1440 和 390 像素浏览器验证：两种模式、片段起点播放、超出范围禁用、草稿恢复、所有图片类别清空、保留素材与提示词、无横向溢出、模型切换。
- 浏览器用实际前端脚本和隔离 API fixtures；视频响应支持 Range，与线上服务一致。没有进行付费模型生成测试。
- 发布期间以 Linux 的 ark-video-workflow 服务账号生成测试视频、截取并校验时长，检查通过。
- 公网 4 个修改的静态文件字节一致，健康接口 200；生产数据库副本的历史任务分页验证通过。
