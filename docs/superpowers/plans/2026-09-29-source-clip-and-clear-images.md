# 视频片段与清空参考图 Implementation Plan

**Goal:** 落实用户已批准的完整视频/指定片段时长方案，并提供清空本次参考图的简洁入口。
**Architecture:** source_clip 作为独立草稿字段保存，null 表示完整视频，{start,duration} 表示片段。模型仍使用编辑任务要求的 duration=-1，工作进程先截片再打码，缓存键包含片段。非编辑模型保持已有生成秒数设置。清空只移除草稿引用，不删除素材实体。
**Tech Stack:** FastAPI、SQLite JSON 草稿、原生 JavaScript、FFmpeg、pytest、Playwright。
**Spec:** 本对话已批准方案。直接在当前工作区执行，按线上基线定点发布，保留现有工作副本备份。

- [x] 新增 source_clip 校验/截取与测试：整数时长 4–30 秒、有限非负起点、范围不得超出原片、保留音轨、失败不复用半成品。
- [x] 接入草稿、提交预检、工作进程和历史摘要；验证更换片段不复用完整视频缓存、恢复任务保留片段。
- [x] 加入模式、时长、起点和原片片段预览；验证旧草稿、模型切换、元数据尚未加载和窄屏布局。
- [x] 加入“清空参考图”：清空所有图片类型，取消可选参考项，刷新计数并保存；保留原视频、人物视频、提示词与历史库，处理进行中的上传/保存竞态。
- [x] 运行接口/工作进程/浏览器验证，备份发布；检查队列、服务与历史数据。
