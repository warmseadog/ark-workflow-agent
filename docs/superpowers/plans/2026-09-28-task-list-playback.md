# 任务列表、命名与播放优化实施计划

> 按 superpowers:executing-plans 在本会话逐项实施，用户已确认上一轮方案并要求保存 version 1 后执行。

**Goal:** 任务列表分页、名称可编辑、单播放器流畅预览与原片下载。
**Architecture:** SQLite 分页摘要与独立名称表保留原始任务快照；任务列表独立前端模块；后台单线程生成缓存播放副本，原始输出不变。
**Tech Stack:** FastAPI、SQLite、原生 JavaScript、FFmpeg、pytest、Playwright。
**Spec:** 本会话用户已批准的修改方案（2026-09-28）。

## 约束
- 本地 main 的 03a8da7 / version-1 是修改前快照，不移动标签。
- 每页 10 条，按创建时间和 id 倒序；详情按需读取；保留历史任务。
- 名称旁小笔，Enter 保存、Esc 取消；更新显示名称不改变任务参数及远端任务。
- 默认名称使用人物或“视频”加时间；流畅预览与原画可切换，下载保留原片。
- 已生成视频后台补建缓存，新生成视频自动处理；不提交新的付费生成任务。

## 审查重点
- 任务生成参数快照不因改名或默认命名被改写。
- 过时的分页请求不得覆盖新页面；轮询不能覆盖输入中的名称或中断播放器。
- 重命名和下载名称应拒绝空白、控制字符，界面使用 textContent。
- 预览失败不改变生成成功状态，不能重复提交模型任务。
- 名称、分页与播放均保留现有本机访问鉴权，删除任务后不能继续经接口访问。
