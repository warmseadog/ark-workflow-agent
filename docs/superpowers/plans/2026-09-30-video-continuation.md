# 视频智能续写实施计划与约定

依据：用户已确认方案二、保留现有提示词、Doubao-Seed-2.1 Lite 后台可配置、目标时长减原片时长 >= 1 秒触发。

## 行为

1. target_duration 独立于 source_clip。新提交不以放慢补足时间；历史任务快照及重试保留原语义。
2. 后台探测真实源时长（选择片段则按片段）。达到阈值时冻结 LLM 配置和 Skill，在任何人物准备/视频付费前检查密钥及模型兼容性。
3. 原提示词原样生成基础片；抽取基础片结尾 8 帧和时间戳，由多图 LLM 生成结构化续写计划。原提示词、模板不可覆盖。
4. 独立 extend 视频任务，明确自然续写、正常速度、锁定人物服装场景。输出目标总时长，不携带编辑阶段不延长指令。
5. 保存阶段记录、计划和独立远端 ID；失败保留基础片，可继续阶段二。提交结果不确定时禁止自动重发。
6. 续写前重新核验原素材授权。只有完整流程成功才公开最终输出。新增管理接口沿用管理员权限，不返回密钥。

## 文件与接口

- continuation_settings.py / continuation_llm.py：可配置多图 LLM 及纯文本 Skill、严格结构化返回；独立实现并以模拟网络测试。
- continuation.py / continuation_media.py：阈值、抽帧、阶段执行、结果校验；production_router/worker/store 集成。状态使用生产库独立表，租户隔离。
- video_provider.py：新增 extend 方法，使用同一轮询/下载与错误语义，显式 omni_reference_task_type=extend。
- generation-options.js / production.js：独立 target_duration，恢复和预览保持正常速度。
- 后台配置页面：模型、地址、密钥、开关、超时、Skill 可编辑，默认 Doubao 模型、空密钥。

## 验证

测试先行：0.999/1/1.001 秒边界、无密钥前置阻断、原提示词未改、阶段二重试不重做基础片、断电提交不确定不重发、权限重验、密钥不公开、真实 FFmpeg 时长与抽帧、桌面/移动端时长选择恢复、配置管理员限制。完成后运行完整测试并单独代码审查。不调用收费服务，不自动部署新功能。
