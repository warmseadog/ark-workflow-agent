# 视频智能续写

本次实现位于 `codex/video-continuation`，已于 2026-09-30 部署到服务器，尚未调用真实收费模型。

## 使用

管理员打开「后台配置 → 视频续写」，填写 API Key 后保存。默认模型为 `doubao-seed-2-1-lite-260915`（Doubao-Seed-2.1 Lite），接口为火山方舟 `/api/v3`。可调整开关、模型 ID、接口地址、超时和 Skill。配置为全局管理员配置，普通用户无法读取或修改，密钥不返回浏览器。修改接口地址时会清空此前密钥。

生产工作台使用 Seedance 2.5，将目标时长设为比原片或选定片段长至少 1 秒，自动进入两阶段流程。例如原片 8 秒：8.999 秒不触发；9 秒触发。判断使用后端探测值，界面显示的四舍五入秒数不参与判断。少于 1 秒的差值保持原片时长，不拉慢或补静帧。

源片缩短仍采用正常速度截取。新界面不再创建 `retime: slow`；历史任务快照和正在恢复的旧任务不改写。续写基础片需至少 4 秒，最终目标不超过 30 秒；其他视频模型继续原有流程。

## 流程

1. 保存目标时长，与源片选择分开存储。提交时核验素材权限和续写配置；缺少 LLM 密钥或视频模型处于演示模式时，在任何付费准备之前阻断续写提交，保留草稿。
2. 将现有原始提示词和素材按原有流程发送到视频编辑模型，生成基础片。原始提示词和模板保持原文。
3. 抽取基础片最后 3 秒的 8 张关键帧、真实时间戳，将原始提示词、素材角色、实际基础片时长和目标时长一起交给多图 LLM。
4. Skill 生成结尾状态、不变要素、覆盖新增时段的动作规划和续写提示词。默认服务于人物/服装展示，保持人物、服装、发型、配饰、场景，允许新增动作与运镜自然展开。默认不增加对白或新人物。
5. 将基础片作为唯一 Video1，独立调用 Seedance 2.5 的 `omni_reference_task_type=extend`。续写提示词独立构建，避免继承编辑阶段禁止延长的控制指令。
6. 校验服务商返回的完整成片总时长。小数目标采用向上取整请求后在帧精度内裁切，不变速。异常结果保留基础片和远端任务编号，不猜测拼接、不用定格补足。

## 失败与恢复

基础片、规划结果及续写任务 ID 分别持久化于本租户存储。查询或下载失败时，「恢复」只继续续写阶段；基础片不会再次生成。服务商明确返回续写任务失败后，用户主动恢复可创建新的续写任务，保留此前编号。请求结果不确定且未保存任务 ID 时禁止恢复重发，需核查服务商记录。

配置与 Skill 版本在提交时冻结，修改后台配置只影响新任务。LLM 结果作为结构化数据解析，不执行生成的代码。进入规划、提交续写和保存最终视频前重验原素材授权，生成视频的新文件指纹不绕过源素材授权。

任务详情展示续写提示词、LLM 模型和 Skill 版本，基础片生成后可以单独查看；最终成片仅在全部步骤成功后可下载。

## 验证边界

本地测试涵盖阈值、配置权限与密钥、真实 FFmpeg 抽帧裁切、两阶段失败恢复、素材撤权、提交不确定、桌面及手机表单操作。API 请求用模拟响应验证；尚未填写真实密钥进行收费验收，因此实际模型的剧情质量、衔接效果和延长输出形式仍需真实任务验证。

最终全量回归：`pytest tests -q -p no:cacheprovider`，**940 passed，1 skipped**（371.93 秒）；1 条既有 Starlette 弃用警告。独立审查的三项问题均有先失败后通过的重现测试，最终全量包含这些修复。测试使用独立存储目录，无真实外部模型请求。

接口依据：[视频生成任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh&redirect=1)、[Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)、[模型公告](https://docs.volcengine.com/docs/ark/model-release-announcement?lang=zh)。
