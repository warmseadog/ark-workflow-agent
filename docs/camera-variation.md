# 拍摄灵感与换拍法生成

制作页常驻展示「拍摄灵感（选填）」编辑框，不再通过「换个拍法」展开，制作页也不显示模型配置链接。按钮固定为「灵感生成」。有有效灵感时沿用多模态规划模型结合模板和素材生成摄影方案；空白、空格或换行提交后完整走普通生成流程，不触发摄影规划或拍法轮换，仍支持普通续写。原有「生成视频」按钮始终不采用编辑框内的灵感。每次只提交一条任务，任务创建成功后清空灵感但保持方框展示；切换草稿也清空。失败保留输入，「清空」只清除当前灵感。

## AI 灵感辅助

「AI 灵感辅助」调用独立的纯文本接口 `POST /api/production/inspiration-assist`，请求仅有 `inspiration` 字符串（最多2000字，可为空）。有输入时完善该想法，空输入时生成一条穿搭展示拍法；结果回填输入框，用户可修改后点击「灵感生成」。辅助允许在素材尚未选择时使用，不读取草稿、视频、图片或历史任务，不创建视频任务，也不占用视频排队额度。文本模型调用本身可能产生提供方费用。

辅助模型只接收内置 Skill 正文和本次用户文本，目标60～120字、最多500字，关闭豆包模型深度思考，默认512 tokens、15秒总截止时间，最多一次请求，不自动重试。其他兼容模型需管理员选择支持短文本生成的接口。部署前需用实际模型测量耗时；此处参数不代表实测速度或服务方保证。

Skill 位于 `app/skills/shooting-inspiration/SKILL.md`，基于 dexhunter/seedance2-skill 的中文版本（固定提交 `516284d5bab58361bfdfed3cc96cee3e837d4c44`），来源与许可在相邻 NOTICE.md、LICENSE 中。适配版只保留拍法写作方法及人物穿搭约束，随发布加载并缓存，更新后重启进程；不在请求中访问 GitHub。

管理员在「后台设置 → 换个拍法 → AI 灵感辅助」配置独立开关、模型、输出预算和超时。默认复用上方拍法模型的地址与密钥，模型留空则也复用模型 ID；可在同一接口下单独填写快速文本模型，或关闭复用后填写独立接口。辅助配置保存到 `private/inspiration-settings.json`，不会修改已有拍法配置或历史任务。更换独立地址且未提供新密钥时清除旧密钥。启用、复用与密钥状态仅管理员可配置；普通用户只能调用辅助接口。

辅助使用独立加载状态，等待期间不额外锁住普通视频生成。每个实际操作账户最多一个请求，同一站点最多四个辅助请求，通过独立OS文件租约跨worker限流。清空、切换草稿、页面离开或提交视频会作废旧结果；请求期间编辑文字时结果不会覆盖新输入。取消浏览器请求不保证提供方取消计费。辅助失败、超时和异常输出均保留原文。日志只记录请求标识、模型、Skill版本、耗时与状态，不记录原文或密钥。

这次改造保留原有视频worker与摄影规划链路；「灵感生成」仍可能包含既有多模态规划耗时，辅助结果不冒充已完成的内部镜头方案。

## 本地实验：用户意图优先

后台「换个拍法 → 提示词版本」可选「原版（严格参考）」或「用户意图优先（测试版）」。默认仍为原版。原有 `template`、`skill` 及严格模式系统提示词保持不变；测试版另存 `user_priority_template`、`user_priority_skill`。切换只保存当前版本的编辑内容，不把测试版文本写回原版；切回后可继续使用原来的自定义模板。模式名存为 `prompt_mode`，缺失该字段的配置和旧任务按 `strict` 解释。

测试版以当前用户灵感为创作依据，接受CCD质感、微虚化、光照、调色、动作速度、运镜以及明确要求的造型/场景调整。未指定变更的部分仍沿用素材。AI 灵感辅助也跟随此开关使用独立的 `USER_PRIORITY.md`，不改动原有 `SKILL.md`，仍只接收本次用户文字和所选Skill。

新任务会冻结提示词模式、两套配置与版本。测试版的规划结果由程序加上模式和用户原话，并通过独立的最终提示词拼接分支提交；不再注入原版“保持视觉风格”“禁止调色或造型变化”等创作限制。用户创作原文保留在最终提示词中，并明确优先于规划建议，防止摘要遗漏；不存在的素材引用编号转换为普通文字，不生成虚构素材绑定，任务内的原始记录不改写。三种provider协议共用这一分支。已有任务继续使用自己的快照，恢复任务不会按当前后台选项重新规划。

测试版保留JSON结构、1–3镜头、时序覆盖、长度和素材编号检查，允许用简短文字表达更多景别、机位和运镜。它改变创作优先级，不改变模型接口协议或任务权限。模型若仍返回拒绝/未采纳方案，系统报告规划未完成，避免把拒绝结果当作成功方案提交。普通「生成视频」及空白灵感的回退路径不使用测试版。实际视觉效果仍需真实模型验收。

本地实验基线为 `a81caad`，已先同步至本地与远程 `main`；实验改动保留在本地 `codex/user-priority-prompt-test`，不在本次任务中部署或推送。

## 原版拍法规则与配置

原版的人物、发型、穿搭、配饰、场景、光照和视觉风格受固定规则约束。差异来自景别、机位、构图、运镜和展示重点。同素材最近四次拍法参与默认方案选择。模型输出经过结构与时序校验，但成片一致性仍需人工验收。

管理员和超级管理员可在「后台设置 → 换个拍法」编辑独立的接口基础地址、模型 ID、API Key、超时、默认模板和 Skill。接口需要兼容 Chat Completions，并支持图片输入及 JSON 输出。视频生成模型仍由制作页配置。更换接口地址会清除旧密钥；同地址保存时密钥留空表示保留。

效果优先的 Pro 接入配置：doubao-seed-2-1-pro-260915，开启深度思考，reasoning_effort=high，输出预算 32768 tokens（包含思考内容），超时 300 秒。后台支持修改以上参数。旧任务快照缺少思考配置时仍采用原来的关闭思考、3500 tokens 设置。截断的返回不会提交视频生成。当前仍使用 JSON Object 并执行程序结构校验。

密钥入口：https://console.volcengine.com/ark/region:cn-beijing/apikey 。用户自行复制密钥到后台 API Key 输入框并保存。等待密钥期间配置会明确显示未配置，且任务预检不会调用模型。使用普通方舟 API Key，与后台所填标准 API 地址对应。

配置和灵感在提交时冻结，后台后续修改只作用于新任务。管理员任务详情展示实际拍法、未采纳的冲突、最终提示词及配置版本；普通用户仍不获取这些内部规划字段。规划失败尚未向视频模型提交；用户可恢复自己的任务，沿用任务冻结的配置。修改错误的模型配置后应新建任务。已取得远端任务 ID 的恢复不会再次规划或重复付费提交。历史空白换拍法任务保留旧意图，同一提交标识重试仍返回原任务。

换拍法暂不同时启用续写。纯粹要求换人、换衣服、换场景等冲突输入会停止生成。音频失败时如需关闭音频，应回到制作页关闭音频并重新点击「灵感生成」，避免普通重试丢失摄影方案。

普通用户可提交换拍法、恢复及重试自己符合条件的任务，沿用原有账户额度、排队规则和归属检查。后台配置仅管理员可编辑；密钥保存在私有配置与任务快照中，不返回浏览器。

部署使用完整 release bundle、队列空闲检查、停写快照和原子切换。一旦产生换拍法任务，降级目标必须声明 camera-variation-v1 读取能力；保留旧代码并不代表可绕过数据兼容性检查回退。
