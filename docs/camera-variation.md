# 换个拍法

制作页选择原始素材，所有已登录用户均可点击「换个拍法」展开编辑框。有有效灵感时点击「按灵感生成」，由多模态规划模型结合模板和素材生成摄影方案。空白、空格或换行显示「正常生成」，提交后完整走普通生成流程，不触发摄影规划或拍法轮换，仍支持普通续写。普通生成按钮始终不采用编辑框内的灵感。每次只提交一条任务，成功后清空灵感并收起编辑框；切换草稿也清空灵感。

人物、发型、穿搭、配饰、场景、光照和视觉风格受固定规则约束。差异来自景别、机位、构图、运镜和展示重点。同素材最近四次拍法参与默认方案选择。模型输出经过结构与时序校验，但成片一致性仍需人工验收。

管理员和超级管理员可在「后台设置 → 换个拍法」编辑独立的接口基础地址、模型 ID、API Key、超时、默认模板和 Skill。接口需要兼容 Chat Completions，并支持图片输入及 JSON 输出。视频生成模型仍由制作页配置。更换接口地址会清除旧密钥；同地址保存时密钥留空表示保留。

效果优先的 Pro 接入配置：doubao-seed-2-1-pro-260915，开启深度思考，reasoning_effort=high，输出预算 32768 tokens（包含思考内容），超时 300 秒。后台支持修改以上参数。旧任务快照缺少思考配置时仍采用原来的关闭思考、3500 tokens 设置。截断的返回不会提交视频生成。当前仍使用 JSON Object 并执行程序结构校验。

密钥入口：https://console.volcengine.com/ark/region:cn-beijing/apikey 。用户自行复制密钥到后台 API Key 输入框并保存。等待密钥期间配置会明确显示未配置，且任务预检不会调用模型。使用普通方舟 API Key，与后台所填标准 API 地址对应。

配置和灵感在提交时冻结，后台后续修改只作用于新任务。管理员任务详情展示实际拍法、未采纳的冲突、最终提示词及配置版本；普通用户仍不获取这些内部规划字段。规划失败尚未向视频模型提交；用户可恢复自己的任务，沿用任务冻结的配置。修改错误的模型配置后应新建任务。已取得远端任务 ID 的恢复不会再次规划或重复付费提交。历史空白换拍法任务保留旧意图，同一提交标识重试仍返回原任务。

换拍法暂不同时启用续写。纯粹要求换人、换衣服、换场景等冲突输入会停止生成。音频失败时如需关闭音频，应回到制作页关闭音频并重新点击换个拍法，避免普通重试丢失摄影方案。

普通用户可提交换拍法、恢复及重试自己符合条件的任务，沿用原有账户额度、排队规则和归属检查。后台配置仅管理员可编辑；密钥保存在私有配置与任务快照中，不返回浏览器。

部署使用完整 release bundle、队列空闲检查、停写快照和原子切换。一旦产生换拍法任务，降级目标必须声明 camera-variation-v1 读取能力；保留旧代码并不代表可绕过数据兼容性检查回退。
