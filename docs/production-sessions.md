# 本地视频草稿与后台任务

工作台现在区分可编辑的草稿与生成任务。点击生成后会保存当前输入的快照并进入后台队列，页面继续可编辑；可以新建草稿或复制当前草稿制作下一条视频。

## 自动保存

素材保存在 storage/assets，草稿和任务状态保存在 storage/production.db。工作台自动保存视频、人物图、服装图、提示词、打码参数和模型参数；页面显示“已保存”后可刷新恢复。同一浏览器优先打开上次选择的草稿，其他情况下从草稿列表选择。上传或保存未完成时离开页面会提示。浏览器清除站点数据不会删除服务器上的草稿和素材，但会清除当前草稿选择及尚未确认的提交标识。

这是当前本地项目的数据保存，不是账号或跨设备同步。请保留整个 storage 目录。API Key 等私密参数不写入公开草稿；运行时的私有配置快照包含用于恢复任务的凭据，应与现有 private 配置一同保护。

## 任务操作

- 新建草稿：开始新的输入。
- 复制草稿／任务：复用素材并修改；历史任务仍可复制现存素材。
- 生成视频：提交当前已保存版本，生成任务不会随着之后的编辑变化。
- 撤销排队：仅对尚未开始、未提交到模型服务的任务开放。
- 继续查询／下载：恢复原服务商任务，不重新生成。过期结果地址会通过同一个任务刷新。

队列最多同时处理两个任务，本地打码一次处理一个。关闭或刷新网页不会停止服务进程中的队列；关闭服务会中断执行，重新启动后恢复本地阶段或继续查询已知云端任务。

## 错误处理

真人素材被服务商拒绝会显示失败原因与 Request ID，保留输入供修改后复制生成。它不是等待中的任务，不会自动反复重试。若提交请求已发出但没有拿到可确认的服务商任务 ID，状态为“提交结果待确认”；请先核对服务商记录，避免重复生成。

素材和草稿自动保存失败、版本冲突均会保留当前编辑并提示。其他页面修改同一草稿时不会静默覆盖，可以将当前编辑保存到新草稿。

## 验证

pytest 包含持久化、乐观版本冲突、不可变快照、幂等提交、并发上限、Windows 队列锁、恢复查询及下载等回归测试。

`tests/browser_production_session.py` 在桌面与手机宽度测试草稿、素材、预览、链接导入、模板、模型设置和任务列表。

加 `--integration` 使用独立临时数据库和真实本地 HTTP 服务、SQLite、队列及模拟模型生成；检测器边界使用合成视频复制桩，不调用付费模型或访问用户素材。

## 任务详情与删除

每个任务提供“查看详情”，可展开查看状态、编号、错误、提示词、模型及打码参数、关联素材。历史任务中未保存的信息明确显示为未保存。

“删除任务”确认后从任务列表移除，刷新后仍生效；保留草稿、素材和本地视频文件。未开始的本地排队任务会同时撤销；正在执行或正在恢复云端查询的排队任务不能删除。需要处理的任务删除记录不会取消服务商端可能仍在执行的任务。
