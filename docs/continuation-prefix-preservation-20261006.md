## 实现

- 基础片视频流只做封装转换，不经过编码器或滤镜。只对新增尾段调整尺寸、帧率和编码，再拼接视频流。
- 使用原始轨道时间基，保留帧原始时间戳；读取校验帧时明确设置 `-copyts` 与 `-enc_time_base demux`，避免默认 rawvideo 时间基把微小时间变化取整。
- 最终前段逐帧比较解码画面 MD5、呈现时间和持续时间。时间使用精确有理数比较，不用相似度容差。
- 合成要求基础片为从零开始的恒定帧率，仅允许原轨道一个 tick 的时间量化误差；不符合条件则拒绝发布，不能静默变速或重新编码基础片。支持模型常见的 H.264 基础片，编码不兼容且无法通过验证时保留原片。
- 保留基础片原音频内容和起始偏移，新增段使用尾段音频；缺少音轨的一段补静音。音频单独编码，视频前段不重编码。
- 接续点使用低分辨率帧差与附近动作变化估计，拦截明显跳变。这是保守的异常检查，不代表人物身份、服装细节或动作质量已通过语义级审核。
- 所有验证通过后才原子替换成片；失败不覆盖既有输出，并清理临时文件。
- 接续检查失败进入 `needs_attention`。用户点击“重新生成尾段”并确认新的模型调用费用后，才清除旧尾段远端 ID 并重新提交尾段；保留基础片和规划，记录旧任务 ID，不自动付费重试。
