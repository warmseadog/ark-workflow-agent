# 并发与参考视频时长滑条发布记录

用户确认：延长时放慢原片动作，缩短时截取片段。2026-09-29 发布到原服务器。

## 改动

- 全局任务执行线程和调度总名额从固定 2 改为默认 10，由 `APP_VIDEO_WORKERS` 控制；继续遵守账号并发限制、租户公平轮询和单进程派发锁。视频转码/打码保留独立 CPU 调度锁。
- 删除时长模式选择器。滑条使用整数索引映射到 1 至模型上限的整数秒，并插入参考原片实际时长的小数刻度；默认原片时长，草稿恢复已选择时长。
- Seedance 2.5 默认完整原片，缩短截取、延长放慢；保留原文件，输出 H.264，音轨通过 atempo 调整，补齐末帧并维持正常帧率。提交仍使用官方编辑参数 duration=-1，由处理后的视频承载时长。
- Seedance 2.0 仅提交受支持的整数秒或自动时长 -1；小数原片刻度明确提示模型自动时长，不假称精确小数输出。
- 原片时长由服务器轻量元数据接口补读，覆盖恢复素材和浏览器不支持的上传编码；不为读取时长下载已保存视频。
- 生成声音/音乐与生成视频按钮共同行布局；手机保持同一水平线。保留不选视频时保存模型/声音设置的能力。
- 初始排队提示改为等待执行名额，避免误显示为已经开始准备人物。

## 验证

- 本地相关后端和集成浏览器回归 116 项通过；更新旧声音测试的侧栏导航后，2 项声音开关/刷新恢复/无声重试测试通过，共 118 项。
- 浏览器覆盖 1440 / 390 / 320 像素：7 → 7.7 → 8 → 9 刻度、9 秒慢放参数、草稿刷新、非法 1 秒禁用、模型切换、声音对齐、实际 API 提交快照、无横向溢出。
- 真实 FFmpeg：截取目标帧、3 秒带音轨放慢到 5 秒、2 秒无声素材放慢到 30 秒、原文件不变。
- 调度测试：同时进入 10 个执行线程，无重复领取，第 11 个等待释放名额；既有租户配额/轮询测试保持通过。
