## 已批准范围

## 实施决定

- 隔离采用独立用户 SQLite/目录，替代所有旧表逐条添加 owner_id。现有模块已经以 storage_dir 为边界，复用这一边界可降低遗漏旧查询导致越权的风险。初始管理员保持原目录，其他账户使用 users/<服务器生成ID>。账户数据库集中管理；模型、存储及打码配置只在根目录共享。
- 请求显式解析当前账户的 Settings；后台任务携带明确 Settings，不能依赖请求上下文。
- 共享后台资源统一调度，独立目录并不代表无限硬件资源。管理员默认不浏览别人的媒体；跨用户任务概览单独接口、记录审计。
- 旧 discovery/workflow 接口暂保留管理员专用，普通用户不能绕过生产接口访问旧全局任务库。
- 新登录通过 APP_AUTH_ENABLED 显式启用；上线环境必须启用，认证库为空时不得退回匿名访问。单机开发兼容模式仅用于本地与原回归测试。
