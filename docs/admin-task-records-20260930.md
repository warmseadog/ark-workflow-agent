# 管理员任务记录按用户筛选

管理员进入「任务记录」时默认展示全部用户，可通过「所属用户」切换到指定账号。列表显示任务所属用户名，筛选后从第一页开始，每页 10 条，刷新与自动轮询保留筛选。停用账号仍可查询，已删除任务不展示。

管理员可以查看他人的详情、任务素材、打码预览及生成视频，播放和下载均使用带用户及任务范围的管理员接口。他人的任务只读；自己的任务继续保留重命名、复制、取消、重试、删除等原有操作。普通用户仍仅访问自己的任务，筛选控件隐藏，管理员接口返回 403。

新增接口 `/api/admin/task-records` 提供分页及用户选项。详情和媒体接口均在读取前检查管理员角色、账户、任务可见性；素材还校验是否属于该任务快照。用户目录仅返回 ID、用户名和启用状态。打开详情记录审计，列表轮询不重复写审计。旧版历史任务复用既有归属规则，兼容旧打码文件名；缺失视频不会影响列表加载。

后续权限修复补齐了直接媒体读取的应用审计：即使跳过详情，直接下载成片、读取打码视频、播放文件、原始素材或缩略图，也会记录跨用户 `view_user_media` 事件。由会话中间件在成功响应时写入，按操作者、所属用户、任务和资源在 SQLite 中原子去重，60 秒内的 HEAD/Range/重复读取合并；其他资源、其他操作者及窗口外访问分别记录。该记录表示允许访问，不表示文件传输已全部完成；读取自己的媒体和失败请求不会产生跨用户成功读取记录。
