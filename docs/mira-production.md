# Mira 正式工作台接入

Mira 设计资源已适配到 FastAPI/Jinja 正式模板。原始 `ui/mira/` 保留为设计预览；生产界面加载 `app/static/mira/`，不加载 `mira-workspace-preview.js` 或旧布局快照。

## 登录与页面

- 未登录访问工作台仍通过原有认证边界跳转 `/login`。该页面展示已授权公开的两条 MV，点击 Log in 打开真实登录弹窗。
- 认证继续使用 `account.js`、`login.js` 和 `/api/auth/*`：HttpOnly 会话、CSRF、错误密码提示、跨标签身份通知和退出逻辑均保留。
- 登录窗支持关闭按钮、Esc、点击遮罩与焦点返回；关闭时清空密码。减少动态效果时不自动播放视频；后台标签页和打开登录弹窗时暂停。
- 制作流程、任务记录、人物库、视频库、后台配置、用户管理和修改密码共用 Mira 样式与导航。模型、素材、任务和用户信息仍取自真实接口。
- 普通用户可只读打开 `/videos` 页面；匿名访问仍要求登录，视频 API 的原有租户隔离和管理员权限检查不变。
- 图标脚本只替换装饰图形，当前导航状态由现有 `workspace.js` 管理。业务表单、字段 ID 和原生产脚本顺序保留。

## 资源与维护

`mira-system.css` 和 `mira-workspace-skin.css` 来自设计预览，`mira-production.css` 负责正式模板适配。`mira-cover.js` 仅处理公开影片与登录弹窗，不拦截上传、生成或保存操作。Lucide 许可证随图标位于 `app/static/mira/vendor/`。

MV 使用原始视频与定帧，按 cover 方式裁切。这里只发布已在设计目录获准公开的封面素材，不将用户上传或生成结果放入公共静态目录。

## 回归与发布

`tests/test_mira_integration.py` 使用隔离 SQLite 账号、真实应用路由和浏览器验证登录失败/成功、上传、草稿恢复、退出、共享页面权限、轮播、减少动态效果、弹窗交互以及手机/横屏/桌面导航与布局。模型供应商不参与这些测试。

同时运行完整既有回归，检查人像授权、续写、任务与后台操作。服务器发布沿用新 release 目录、隔离回归、空闲检查、数据库备份、原子切换、健康检查与失败回滚流程，不迁移或覆盖生产数据。
