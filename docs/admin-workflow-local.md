# 管理与生成工作流：本地改版说明

2026-10-06：管理员复制到本人账号及图片预览改动已正式发布，见 [发布记录](deployment-20261006-mediakit-admin-copy.md)。下文其余章节保留最初改版说明。

本次对应需求 4–10，保留既有的参考优先提示词模板及历史任务。实现位于本地分支 `codex/admin-workflow-local`。

## 账号与管理权限

| 操作 | 普通用户 | 管理员 | 超级管理员 |
| --- | --- | --- | --- |
| 创建自己的视频任务 | 可以 | 可以 | 可以 |
| 查看模板、正文和完整提示词 | 隐藏，接口也不返回 | 可以 | 可以 |
| 管理普通用户、还原其任务草稿 | 不可以 | 可以 | 可以 |
| 管理管理员账号 | 不可以 | 不可以 | 可以 |
| 恢复已删除账号 | 不可以 | 不可以 | 可以 |
| 查看全局并发 | 不可以 | 可以 | 可以 |
| 修改全局并发、模型凭据与系统配置 | 不可以 | 不可以 | 可以 |

旧账号首次升级时，优先将启用的初始管理员提升为超级管理员；若初始管理员已经停用或降级，选择另一位启用的管理员。保留账号 ID、密码、会话和任务归属，不会重新启用已停用账号。系统阻止删除、停用或降级最后一位可用超级管理员。

新用户名规范化后为 2–20 个字符，支持中文、字母、数字和允许的常用符号；已有较长或单字符用户名仍可登录。

“删除账号”采用软删除：退出该用户现有会话，取消尚未提交的排队任务，保留历史。存在运行中或已提交到服务商的排队任务时不能删除。超级管理员可恢复删除的账号。

## 时长、任务还原与对比

- 生成参数区增加“恢复原片时长”。点击后清除裁剪起点、手动片段时长和续写目标，并保存草稿。原片有小数秒时保留原值；所选模型不能精确支持该时长时明确提示。
- 2026-10-06 调整：管理员任务列表使用“复制到我的草稿”。原任务的有效输入素材被完整校验并独立保存到管理员账号；草稿保留提示词、模型参数和已校验人物关联，可直接编辑或生成。新视频使用管理员的并发与排队额度，归管理员所有；原任务、原草稿和双方登录会话保持不变。
- 复制记录原用户和来源任务，重复请求具备幂等保护。提交状态不明确的任务禁止复制重提。未启用的旧参考不参与复制；必要素材丢失、被修改或授权撤销时明确拒绝。真人引用的撤销约束继续有效。
- 旧代操作地址保留兼容；从旧页面选择“复制到我的草稿”会退出代操作范围，跳转至管理员自己的新草稿。
- 制作页参考图、任务详情图和人物库照片支持点击及键盘放大查看原图；可按 Escape、关闭按钮或点击遮罩退出。制作页去除图片/视频文件名，保留任务名称、素材操作与状态。
- 播放列表上方增加视频对比入口，左侧原动作视频、右侧生成结果。支持同步播放/暂停、拖动与倍速，只播放一路音频。裁剪视频按起点对齐；生成结果超出原片范围时，左侧停在末帧。关闭后释放媒体资源。

## 提示词与后台设置

普通用户主页不渲染模板、提示词正文和完整预览，草稿、任务快照、复制结果与续写计划接口也不会返回这些内容。普通用户提交只携带素材和允许的生成参数，由服务器保留并使用模板版本和对应规则。用于旧版模板编辑的规则脚本也受管理员权限保护。

管理员可通过后台管理共享模板并查看并发；超级管理员保留完整系统配置界面。模板有未保存改动时，切换或新建前提示；保存期间锁定编辑区域，防止响应覆盖新输入。

后台增加“全局并发上限”：超级管理员可设置为 1 至当前工作线程容量，最高 50。保存即时影响后续调度，调低时等待已有任务自然完成，不终止任务。用户各自的并发、排队限制与公平调度继续生效。

## 耗时与兼容性

任务持久记录等待、打码、上传、模型生成四个主要阶段，另外区分其他处理与暂停时间。模型生成包含服务商排队与轮询；复用缓存会明确标记。历史任务没有分阶段记录时显示未知，不根据更新时间推算；中断恢复只将无法确认的阶段标为未知。

新增账号、分阶段耗时和调度表对应的发布能力标识，后续正式部署必须使用支持这些能力的版本。本轮仅本地修改及验证，不更新 GitHub 或服务器。
