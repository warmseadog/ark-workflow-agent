# 左侧导航与视频库

本次调整将制作页、我的人物、后台配置、用户管理、密码页和视频库统一到共享左侧栏。主导航为制作流程、视频库、任务记录、我的人物；后台配置和用户管理继续按原有管理员权限显示。账户位于底部，点击后展开修改密码与退出登录。手机端使用可收起的导航抽屉。

任务记录通过 `/#tasks` 访问，与制作流程在同一页面内切换，保留草稿状态。复制任务为草稿后自动切回制作视图。原任务的分页、重命名、删除、详情和播放行为继续复用。

视频库入口为 `/videos`，当前范围是本账号已经生成成功的视频（以及有访问权限的历史生成视频），不包含上传的参考视频。桌面显示多列竖版封面，手机显示两列；每页 12 条，靠近底部加载下一页。封面点击后开启播放器，可上下滚动、滑动或使用切换按钮观看前后作品。

`GET /api/production/videos` 在 SQLite 中先筛选成功状态再分页，不读取全部任务快照。`GET /api/production/runs/{id}/poster` 复用现有播放权限、删除状态和源文件检查，在后端提取首帧，按源文件签名缓存 JPEG。图片解码限制并发和时间；解码失败显示占位图。浏览器浏览列表仅请求图片；点击作品后才设置一个播放器的视频地址，切换、关闭时清除旧视频地址并中止过期读取。

验证覆盖：桌面 1440px / 手机 390px 的真实浏览器操作、进入视频库无视频字节请求、分页加载、播放切换与释放、首帧缓存、历史作品、删除保护、未登录访问与跨账户访问隔离。截图保存在 `storage/workspace-preview/`，截图中的视频为自动化测试生成的测试素材。

现有 `test_account_frontend.py` 中四项管理员分页断言仍使用旧交互（50 条分页、筛选需手动提交），与本次调整前已有的 `users.js`（10 条分页、筛选即时生效）不同。已在去除新侧栏的临时模板中复现相同四项失败，本次保持后台现有行为。
