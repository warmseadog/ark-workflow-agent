## 使用方式

后台人物库和“我的人物库”中的真人、虚拟人物均支持点击“添加照片”后一次选择多张；电脑使用 Ctrl / Shift，手机使用相册多选。每张照片依次上传到所选人物，显示进度；单张失败继续处理其余照片，最后列出添加数量、失败文件和原因。视频保持原有单选流程。

手机页面的操作按钮按两列排列，触摸区域至少 44px 高；长名称换行、照片详情单列，弹窗按屏幕高度滚动。页面资源版本为 `20260930-batch-mobile-1`。
